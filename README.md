# Piringku

Pelacak kalori harian berbahasa Indonesia. Satu file HTML, tanpa server dan tanpa instalasi.

- Catat makanan per waktu makan, lengkap dengan daftar makanan Indonesia umum
- Target kalori, kalkulator kebutuhan, ringkasan protein/karbo/lemak
- Grafik 7 hari terakhir
- Data tiap pengunjung tersimpan di browser masing-masing (`localStorage`), tidak dikirim ke mana pun

Angka kalori pada daftar makanan adalah perkiraan, bukan saran medis.

## Jalankan lokal

Buka `index.html` di browser.

## Hosting dengan GitHub Pages

Settings > Pages > Source: `Deploy from a branch` > Branch: `main` / `(root)` > Save.
